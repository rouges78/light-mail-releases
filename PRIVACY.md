# Light@Mail — Informativa sulla privacy

*Ultimo aggiornamento: 14 ottobre 2026*

Light@Mail è un client di posta per Windows che funziona interamente sul tuo computer.

## Dati raccolti
**Nessuno.** Light@Mail non ha server propri, non raccoglie statistiche di utilizzo e non invia i tuoi dati a chi sviluppa l'app né a terzi.

## La tua posta
- I messaggi vengono scaricati dai server del tuo provider (ad esempio Gmail) e salvati **solo sul tuo computer**, facoltativamente cifrati con una password principale.
- Le password degli account sono conservate nel Gestore credenziali di Windows.

## Accesso con Google
Se accedi con Google, Light@Mail riceve un'autorizzazione (token OAuth) usata **esclusivamente** per:
- leggere, organizzare e cancellare la tua posta su richiesta tua (IMAP);
- inviare i messaggi che scrivi (SMTP);
- conoscere il tuo indirizzo email e il nome, per configurare l'account.

I dati ottenuti dalle API di Google non vengono trasferiti a nessuno, non sono usati per pubblicità e non sono letti da persone. L'uso rispetta la [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), inclusi i requisiti di Limited Use.

Puoi revocare l'accesso in qualsiasi momento da <https://myaccount.google.com/permissions>.

## Assistente AI
L'assistente AI facoltativo usa un modello eseguito sul tuo computer (Ollama). I testi dei messaggi non lasciano il computer.

## Aggiornamenti
Per cercare nuove versioni l'app scarica un file pubblico da GitHub. GitHub può registrare l'indirizzo IP della richiesta come per qualsiasi pagina web.

## Contatti
Per domande apri una segnalazione nella pagina [Issues](https://github.com/rouges78/light-mail-releases/issues) di questo repository.

# Light@Mail — Privacy Policy

*Last updated: October 14, 2026*

Light@Mail is a Windows email client that runs entirely on your computer.

**Data collected: none.** Light@Mail has no servers of its own, collects no usage statistics and sends none of your data to its developer or to third parties.

**Your email** is downloaded from your provider's servers (for example Gmail) and stored **only on your computer**, optionally encrypted with a master password. Account passwords are stored in Windows Credential Manager.

**Google sign-in.** If you sign in with Google, Light@Mail receives an OAuth token used **only** to read, organize and delete your mail at your request (IMAP), send the messages you write (SMTP), and read your email address and name to set up the account. Data obtained from Google APIs is never transferred to anyone, never used for advertising and never read by humans. Light@Mail's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. You can revoke access at any time at <https://myaccount.google.com/permissions>.

**AI assistant.** The optional AI assistant uses a model running on your computer (Ollama); message text never leaves your computer.

**Updates.** To check for new versions the app downloads a public file from GitHub, which may log the request's IP address like any web page.

**Contact:** open an issue at <https://github.com/rouges78/light-mail-releases/issues>.
