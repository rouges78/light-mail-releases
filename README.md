# Light@Mail

Client email desktop per Windows, ultraleggero e senza limiti di spazio: tutta la posta in locale,
compressa e indicizzata, con ricerca istantanea anche offline.

## Scarica

➡️ **[Ultima versione](https://github.com/rouges78/light-mail-releases/releases/latest)**: scarica il file `LightMail_x.y.z_x64-setup.exe` e avvialo.

Windows potrebbe mostrare l'avviso di SmartScreen perché il programma non ha ancora una firma
Authenticode: scegli *Ulteriori informazioni → Esegui comunque*.

## Aggiornamenti

Light@Mail controlla da solo se ci sono nuove versioni e chiede conferma prima di installarle.
Ogni aggiornamento è firmato digitalmente: una versione non firmata dal progetto viene rifiutata.

## In breve

- IMAP e POP3, accesso con Google, PEC con configurazione automatica
- protezione anti-phishing, archivio cifrato con password
- smistamento automatico, pulizia newsletter, rimanda e promemoria
- assistente AI locale (Ollama): nessun dato esce dal computer

Questo repository contiene solo gli installer pubblicati.
